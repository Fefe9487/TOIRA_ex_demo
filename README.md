# TOIRA 防爆電器與火災爆炸範例測試

依 [TOIRA 原型](https://github.com/Fefe9487/TOIRA_prototype) 做成的靜態測試站。首頁要輸入邀請碼才會進入；通過後的公司資料、行業模板、評估、報表與後臺，沿用原型同一套畫面。

邀請碼：`1151013`

作業庫只留 10 項，都同時有火災、爆炸危害，並包含防爆電器措施：

1. 可燃性化學品管線液位監測作業
2. 油墨調配與廢液回收作業
3. 化學品入料作業
4. 局限空間作業
5. 石化業製程區歲修作業
6. 鑄造塗模作業
7. 噴漆及上漆作業
8. 槽車卸料管閥連接作業
9. 槽車接地作業
10. 液態化學品分裝與包裝作業

行業模板仍用 `industryMapping.json`，只保留掛到這 10 項的列。資料庫查詢與自選製程也只看這 10 項。情境對照沿用原型已對上的內容，90 個危害組、401 則情境。

## 使用

1. 開啟首頁，輸入邀請碼。
2. 填公司資料。統一編號 `31445632` 可帶入範例公司。
3. 選行業模板，或按「自行組裝製程」。
4. 評估後可儲存、匯出報告。標準 Excel 在網頁版改開 PDF 預覽，與原型相同。

直接打開評估頁而尚未輸入邀請碼時，會回到首頁。這個邀請碼寫在靜態頁面裡，用來擋住一般訪客；它不是伺服器登入。
