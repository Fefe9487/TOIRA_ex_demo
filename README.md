# TOIRA 測試站

依 [TOIRA 原型](https://github.com/Fefe9487/TOIRA_prototype) 做成的靜態測試站。作業庫與原型相同，共 174 種作業。公司資料、行業模板、評估、報表與後臺沿用原型同一套畫面。

進入前需輸入邀請碼。情境對照版本是 `20261005h`：1,400 個危害組、6,193 則情境，文字逐條對上作業庫。行業模板使用完整的 `industryMapping.json`，共 19 個行業、531 列。

嚴重度資料跟原型 `20261011b` 相同。每個危害組與每則情境都有 `ruleSeverity`。預設用原本估算的嚴重度；評估頁打開「職災統計嚴重度」後，改用 110–114 年職災統計。立即危險類型為 S5，職業病依可恢復性為 S4 或 S5。使用說明與標準 Excel 匯出仍與原型相同。常見問答為 2026/10/13 修訂版，共 45 題。

## 使用

1. 開啟首頁，輸入邀請碼。
2. 統一編號 `31445632` 可帶入範例公司。
3. 選行業模板，或按「自行組裝製程」。
4. 評估後可儲存、匯出 PDF 或標準 Excel。需要時可打開「職災統計嚴重度」，或由「使用說明」「常見問答」查看評估方式。

未通過邀請碼時，直接打開評估頁會回到邀請頁。
