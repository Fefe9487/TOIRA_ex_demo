# TOIRA 防爆電器與火災爆炸範例測試

依 [TOIRA 原型](https://github.com/Fefe9487/TOIRA_prototype) 做成的靜態測試站。首頁要輸入邀請碼才會進入；通過後的公司資料、行業模板、評估、報表與後臺，沿用原型同一套畫面。

邀請碼：`1151013`

作業庫只留 10 項，都同時有火災、爆炸危害，並包含防爆電器措施：

1. 可燃性化學品管線液位監測作業
2. 油墨調配與廢液回收作業
3. 化學品入料作業
4. 局限空間作業
5. 石化業製程區歲修作業
6. 鑄造塗模作業
7. 噴漆及上漆作業
8. 槽車卸料管閥連接作業
9. 槽車接地作業
10. 液態化學品分裝與包裝作業

行業模板仍用 `industryMapping.json`，只保留掛到這 10 項的 27 列。資料庫查詢與自選製程也只看這 10 項。情境對照版本仍是 `20261005h`：90 個危害組、411 則情境，文字逐條對上作業庫；其中 6 個職業病組有舊評估序號移轉。

嚴重度資料跟原型 `20261011b` 相同。每個危害組與每則情境都有 `ruleSeverity`。預設用原本估算的嚴重度；評估頁打開「職災統計嚴重度」後，改用 110–114 年職災統計。立即危險類型為 S5，職業病依可恢復性為 S4 或 S5。使用說明、常見問答與標準 Excel 匯出也與原型相同。

## 使用

1. 開啟首頁，輸入邀請碼。
2. 填公司資料。統一編號 `31445632` 可帶入範例公司。
3. 選行業模板，或按「自行組裝製程」。
4. 評估後可儲存、匯出 PDF 或標準 Excel。需要時可打開「職災統計嚴重度」，或由「使用說明」「常見問答」查看評估方式。

直接打開評估頁而尚未輸入邀請碼時，會回到首頁。這個邀請碼寫在靜態頁面裡，用來擋住一般訪客；它不是伺服器登入。
